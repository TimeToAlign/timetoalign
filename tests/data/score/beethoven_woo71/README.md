**Note on measure count discrepancy (371 vs 397):** The ms3 overview table reports
371 measures, which counts unique printed measure numbers (`mn` column). The gold
standard of 397 comes from `wc -l` on the TSV (398 lines − 1 header = 397 data rows),
which counts XML measure containers (`mc` column). The 26-row difference arises from:
(a) 1 anacrusis measure (`mc=1`, `mn=0`) not counted in the printed numbering, and
(b) 25 additional XML measures generated by repeat structures (volta endings and
repeat barlines create extra `mc` entries that share the same `mn`). Both counts are
correct; they measure different things. Tests use the TSV row count (397) as the gold
standard because it represents the total number of measure records the loader must parse.
